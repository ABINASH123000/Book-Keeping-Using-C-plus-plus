Book Shop Inventory Management System

A C++ console-based Book Shop Inventory Management System that manages book details such as author, title, publisher, price, and available stock. The system searches for books using the author and title, displays book information, checks stock availability, and calculates the total cost for the requested number of copies.

Features

Search books by author and title

Display book details and stock information

Check availability of requested copies

Calculate total purchase cost

Read book inventory from a text file

Demonstrates classes, constructors, destructors, file handling, dynamic memory allocation, and exception handling concepts in C++
